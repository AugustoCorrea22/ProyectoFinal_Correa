# ProyectoFinal_Correa

Augusto Correa
22/10/26

Mciroherramienta a desarrollar: Un juego de azar con multiplicadores sobre la ruleta, al estilo de balatro con multiplicadores, "comodines", fichas con poderes, monto a pagar o puntuacion, tipos de crupiers como jefes, cartas de mejora de tipo de jugada (harian de que tu jugada valga mas), o cartas con modificadores (como las cartas del tarot de balatro).
Pero con la diferencia de que empezas con un monto de fichas que tenes que multiplicar para poder seguir jugando y poder pasar el juego.

Serviria para poder pasaar el tiempo con un juego de estrategia y Azar. Con el que pasaras o momentos de felizidad como de ira
(Recomendacion personal: NUNCA VAYAN A UN CASINO, VAN A PERDER TODO, SIEMPRE GANA LA CASA.)
